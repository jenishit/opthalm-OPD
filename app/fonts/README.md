# Self-hosted fonts

Vendored `.woff2` files (latin / devanagari subsets) from the Fontsource packages, so builds and
runtime need no network access to Google Fonts. All families are licensed under the SIL Open Font
License 1.1: Source Sans 3, Lora, Inconsolata, Noto Sans Devanagari, Poppins, Instrument Serif.
To update: install the matching `@fontsource*` package in a scratch directory and copy the files here.
